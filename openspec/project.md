# Localverse - 内网协作平台

## 项目背景

在没有互联网的内网环境中，团队需要一个轻量级的协作工具。Localverse 旨在提供：

- **离线优先**：核心功能无需网络
- **本地数据**：数据存储在用户设备，用户完全拥有
- **可选同步**：通过内网服务器实现多设备同步
- **插件化**：按需加载功能模块

## 目标用户

- 内网环境的开发团队
- 对数据安全敏感的企业
- 需要离线工作的用户

## 核心功能

### Phase 0: 基础设施
- 启动器 (Launcher)
- 本地 JAR 服务
- 通信层
- 数据库服务
- 认证系统
- 插件系统

### Phase 1: 核心应用
- 前端框架
- 知识库 (Wiki)
- 文件搜索 (Finder)

### Phase 2: 协作功能
- 同步服务器
- 同步引擎
- 即时聊天 (Chat)
- 任务管理 (Task)

### Phase 3: 扩展（可选）
- 移动端
- 投票系统
- 日历
- 公告

## 技术选型

| 组件 | 技术 | 原因 |
|------|------|------|
| 后端 | Java 21 | 跨平台，无需安装运行时 |
| 前端 | 原生 JS | 轻量，无构建依赖 |
| 数据库 | SQLite | 单文件，支持 WASM |
| 通信 | WebSocket/SSE/HTTP | 渐进降级 |

## 开发指南

### 环境要求

- Java 21+
- Node.js 18+ (仅开发时需要)
- 现代浏览器 (Chrome/Firefox/Edge)

### 快速开始

```bash
# 1. 克隆项目
git clone <repo>

# 2. 阅读规格
cat openspec/README.md

# 3. 开始开发
# 按 tasks/README.md 中的顺序进行
```

### 构建

```bash
# 构建 Java JAR
mvn package

# 构建前端（如果有构建步骤）
npm run build
```

## 设计原则

1. **简单优先**：能用原生实现就不引入依赖
2. **离线优先**：假设网络不可用来设计
3. **渐进增强**：基础功能保证，高级功能按需
4. **用户优先**：数据属于用户，隐私优先
