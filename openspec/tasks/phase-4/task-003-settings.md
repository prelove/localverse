## 目标

提供统一的全局设置中心，管理用户偏好和系统配置：
1. 语言切换（中/英/日）
2. 主题切换（浅色/深色/系统）
3. 通知设置（各插件开关）
4. 个人资料（用户名/头像）
5. 数据管理（导出/清除缓存）

## 详细需求

### 1. 用户界面

```
┌──────────────────────────────────────────────────────┐
│ ⚙️ 设置                                              │
├──────────────┬───────────────────────────────────────┤
│ 个人资料     │  语言                                 │
│ 外观         │  ● 中文  ○ English  ○ 日本語          │
│ 通知         │                                       │
│ 数据         │  主题                                 │
│              │  ○ 浅色  ● 深色  ○ 跟随系统           │
│              │                                       │
│              │  字体大小                             │
│              │  小 ─────●──── 大                    │
└──────────────┴───────────────────────────────────────┘
```

### 2. 设置项分类

**个人资料**:
- 用户名
- 头像（从设备指纹生成或自定义）
- 角色显示

**外观**:
- 语言（zh/en/ja）
- 主题（light/dark/system）
- 字体大小（small/medium/large）
- 侧边栏折叠默认状态

**通知**:
- 各插件通知开关（Chat/Task/Calendar/Announcement）
- 通知声音
- 桌面通知权限

**数据**:
- 导出所有数据（JSON）
- 清除本地缓存
- 重置应用

### 3. 持久化

设置存储在 IndexedDB/LocalStorage，不需要数据库表。
