## 目标

开发应用主页看板，聚合各插件的关键信息，提供统一的活动摘要和快捷入口：
1. 最近活动摘要（Wiki/Chat/Task/Calendar 最新动态）
2. 任务统计卡片（今日待办、逾期、进行中）
3. 日历预览（本周事件）
4. 未读公告提示
5. 快捷入口（常用操作）

## 详细需求

### 1. 用户界面

```
┌──────────────────────────────────────────────────────┐
│ 🏠 主页                              2026-02-28 周六  │
├──────────────────────────────────────────────────────┤
│ ┌─────────────┐ ┌─────────────┐ ┌─────────────┐      │
│ │  今日待办    │ │   进行中    │ │   未读公告  │      │
│ │     5        │ │     3       │ │      2      │      │
│ └─────────────┘ └─────────────┘ └─────────────┘      │
├──────────────────────────────────────────────────────┤
│ 📅 本周日历                                           │
│  周一  周二  周三  周四  周五  周六  周日              │
│   ·     ·    ●     ·     ●    ●(今)  ·               │
├──────────────────────────────────────────────────────┤
│ 🕐 最近活动                                          │
│  [任务] Alice 更新了 "设计评审"      10分钟前         │
│  [聊天] Bob 在 #general 发了新消息   1小时前          │
│  [Wiki] 更新了 "API 文档"            2小时前          │
└──────────────────────────────────────────────────────┘
```

### 2. 数据聚合

Dashboard 从各插件服务读取数据，不维护独立数据库表。依赖：
- `TaskService.getStats()` - 任务统计
- `CalendarService.getUpcomingEvents()` - 本周事件
- `AnnouncementService.getUnreadCount()` - 未读公告
- `NotificationService.getNotifications(10)` - 最近活动

### 3. 刷新策略

- 打开时自动刷新一次
- 每 60 秒自动刷新
- 用户手动刷新按钮
