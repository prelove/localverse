# Localverse 任务依赖关系图

## Phase 0: 基础设施 (线性执行)

```
┌────────────────────────────────────────────────────────────────────┐
│                      Phase 0: 68小时 (线性)                         │
└────────────────────────────────────────────────────────────────────┘

  📦 Task 001: Launcher 开发 (8h)
       │
       │ 输出: launcher.jar
       │ 功能: 启动/监控/热更新/崩溃恢复
       ↓
  🔧 Task 002: Local JAR 服务 (16h)
       │
       │ 输出: localverse.jar (客户端模式)
       │ 功能: HTTP/WebSocket 服务器
       ↓
  🌐 Task 003: 通信层 (12h)
       │
       │ 输出: 通信层 SDK (JavaScript)
       │ 功能: 请求封装/重连/错误处理
       ↓
  💾 Task 004: 数据库服务 (12h)
       │
       │ 输出: 三模式数据库 API
       │ 功能: Full/Light/Pure 模式
       ↓
  🔐 Task 005: 认证系统 (8h)
       │
       │ 输出: 用户管理/JWT/权限
       │ 功能: 认证/授权/首次配置
       ↓
  🔌 Task 006: 插件系统 (12h)
       │
       │ 输出: 插件框架
       │ 功能: 加载/生命周期/API/事件
       ↓
  ✅ Phase 0 完成
       │
       └─────────────┬─────────────┐
                     ↓             ↓
              Phase 1 开始    Phase 2 开始
                                 (可并行)
```

## 依赖关系总结

### 强依赖 (必须线性)

- Phase 0 所有任务之间
- Phase 1: Frontend 必须先于其他
- Phase 2: Sync Server 必须先于 Sync Engine

### 弱依赖 (可并行)

- Phase 1: Search ⇄ Wiki (可并行)
- Phase 2: Chat ⇄ Task (可并行)
- Phase 3: 所有任务 (完全并行)

### 跨阶段依赖

- Phase 1 依赖 Phase 0 全部完成
- Phase 2 依赖 Phase 0 全部完成
- Phase 2 的插件依赖 Sync Engine 完成
- Phase 3 任务各有不同依赖 (Mobile→Phase2, 其他→Phase1)

## 风险矩阵

```
影响 ↑
高  │ 🔴 Phase 0 延期    🔴 插件系统缺陷
    │ 🟡 同步冲突复杂    
中  │ 🟡 WASM 兼容性     🟡 跨平台问题
    │
低  │ 🟢 文档不完整      🟢 性能优化
    │
    └────────────────────────────────→ 概率
         低        中        高
```

### 风险应对优先级

1. 🔴 Phase 0 延期 → 指派资深开发者
2. 🔴 插件系统缺陷 → 早期验证和迭代
3. 🟡 同步冲突复杂 → 分阶段实现
4. 🟡 WASM/跨平台 → 提供降级方案
